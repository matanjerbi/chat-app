# קליק · צ'אט והיכרויות 18+

אתר צ'אט והיכרויות אנונימי למבוגרים, PWA שניתן להתקין על הטלפון. רץ כולו על Cloudflare.

## ארכיטקטורה
| רכיב | טכנולוגיה |
|---|---|
| שרת + API | Cloudflare Worker (`src/index.js`) |
| זמן אמת (חדרים, הודעות, נוכחות, קאץ', איתות וידאו) | Durable Object `Hub` עם WebSocket Hibernation (`src/hub.js`) |
| מסד נתונים | D1 `blush-db` (`migrations/`) |
| תמונות | KV `blush-media` (אפשר להעביר ל-R2 כשיופעל) |
| וידאו | WebRTC peer-to-peer, STUN של Cloudflare |
| פרונט | `public/` — HTML/JS נקי, בלי build |
| אדמין | `/admin` (למשתמשים עם `role='admin'`) |

## פיצ'רים
- הרשמה אנונימית (כינוי בלבד, 18+), מפתח גישה למעבר בין מכשירים
- חדרים לפי נושא/אזור/רמת תוכן, פתיחת חדרים ע״י משתמשים
- דפדוף באנשים עם סינונים, פרופיל, גלריה פרטית עם הרשאות גישה
- שיחות פרטיות בזמן אמת, "מקליד/ה…", רמות שיחה הדדיות (עלייה באישור)
- תמונות: דחיסה ומחיקת EXIF בצד הלקוח, טשטוש מפורש, צפייה חד-פעמית, חסימת תמונות לפני שהצד השני ענה
- ⚡ קאץ' — התאמה אקראית לפי מגדר ורמה
- אימות סלפי (קוד + תנועה אקראיים) שנבדק ידנית: אדם אמיתי, בגיר, מגדר תואם
- שיחות וידאו — רק פרימיום + מאומתים בשני הצדדים
- דיווחים (קטין → הסתרה מיידית; תמונה ללא הסכמה → הסרה מיידית), חסימות, מחיקת חשבון מלאה
- אדמין: לוח בקרה, תור דיווחים עם הקשר, תור אימותים, ניהול משתמשים (השעיה/פרימיום/אדמין/מחיקה), תמונות, חדרים, יומן פעולות

## פריסה
כל push ל-`main` נפרס אוטומטית דרך GitHub Actions. נדרשים secrets בריפו:
- `CLOUDFLARE_API_TOKEN` — טוקן עם הרשאות Workers Scripts, D1, Workers KV Storage (Edit)
- `CLOUDFLARE_ACCOUNT_ID`

## פיתוח מקומי
```bash
npm install
npm run db:local
npm run dev
```

## לפני השקה ציבורית
- דומיין משלך + הפעלת **CSAM Scanning Tool** של Cloudflare
- תנאי שימוש ומדיניות פרטיות (עו״ד)
- ספק סליקה שמאשר את התחום
- שרת TURN (Cloudflare Calls) לשיחות וידאו מאחורי רשתות סלולריות קשוחות
